# 画面の共通

画面を横断する UI の置き方である。

## ナビと保存

- 押し込む画面のナビは iOS に合わせ、左に戻る、中央にタイトル、右に操作を置く。
- 入力画面の保存は、ナビゲーションの右上に置く。本文の下に保存ボタンを置かない。
- 次の画面へ進む操作は、本文の下に置いてよい。

## 発行

発行は請求書の詳細に置き、下部タブのすぐ上に固定する。
編集画面には置かない。

発行を押すとメニューが開く。PDFをダウンロードするか、アプリで共有するかを選ぶ。
メニューを開いても背景は暗くしない。

## メニュー

書類の複製、変換、削除は、右上のメニューにまとめる。
記帳の右上は三点リーダーとし、メニューはかんたん入力、明細の取込、未承認の明細の 3 つとする。
メニューを開いても背景は暗くしない。

## 日付と選択

- 日付はカレンダーで選ぶ。
- 仕訳と証憑の日付のラベルは取引日とする。
- 取引先と区分は一覧から選ぶ。
- 選ぶ項目は右にカレンダーか ▼ を付ける。

## 検索

一覧の上に検索を置く。形は同じとする。

| 対象 | 探す項目 |
| --- | --- |
| 記帳、証憑、仕訳の選択 | 取引日、金額、取引先 |
| 書類 | 取引先、番号、金額 |
| 未承認の明細 | 日付、摘要、金額 |

## 設定の入口

設定は、ホーム右上のアイコンだけから開く。文言は付けない。

## 部品

部品は Ionic のコンポーネントと CSS 変数だけを使う。
後から `mode` を外して Material を足せるようにする。
