# 概要

個人事業主向けローカル会計プロトタイプの目的と範囲である。

## 目的

触って好感を得て、プロジェクト化につなげる。
見た目だけの感触では足りない。

## 対象

時間単価や月額制のフリーランスである。

## 触ってもらう相手

社内の意思決定者と関連する開発メンバーである。

## データの置き場

状態はメモリ上に置き、永続化しない。クラウドへ保存しない。
外部へは送らない。チャットも固定文で答え、モデルへは渡さない。

## 範囲外（未実装）

未実装の機能はタブに出さない。
設定の「未実装の機能」は初期オフとする。オンにすると、一覧とそれぞれを今回作っていない理由が出る。デバッグ用の画面であり、動くフォームは置かない。

| 機能 | 理由 |
| --- | --- |
| e-Tax 送信 | データを外部へ送らないため |
| 確定申告書 | 申告書の作成は今回の範囲外のため |
| 銀行 API | 外部サーバーと連携しないため |
| 列マッピング | CSV の列を日付・摘要・金額に固定するため |
| 帳票と決算書 | 仕訳帳・元帳・試算表を作らないため |
| 源泉の年間一覧 | 年間の集計は申告の範囲のため |
| 100 万円超の源泉 | デモの請求は税込 100 万円以下のため |
| 証憑の解像度チェックとタイムスタンプ | 見本の読み取りだけを置くため |
| 在庫 | 在庫を持たない業種を対象にするため |
| 部門 | 一人事業で部門を分けないため |
| 給与 | 従業員を雇わないため |
| 法人税 | 個人事業主を対象にするため |

## 作業の進め方

方針と作業単位はリポジトリ内の Markdown に残す。
GitHub の Issue は作らない。
一作業を一ファイルにし、進捗は各ファイルと索引のチェックボックスで見る。
Figma とアプリの実装は、各タスクファイルを開いた回で行う。
