# Figma

ワイヤーの方針とキャンバスの配置である。

## 方針

- Figma には、モバイル幅の低忠実度ワイヤーだけを置く。高忠実度の見た目は作らない。
- 画面の構成を確認するためのもので、プロトタイプの遷移は作らない。
- 並べ方はワイヤーフレームのスキル（`wireframe-design`）の「キャンバスの配置」に従う。

## ファイル

- ファイル: [サンプル会計アプリ](https://www.figma.com/design/ZYT6jUXKaucuuWaJhxUD1v/%E3%82%B5%E3%83%B3%E3%83%97%E3%83%AB%E4%BC%9A%E8%A8%88%E3%82%A2%E3%83%97%E3%83%AA?node-id=0-1)
- 基準フレーム: **390 × 844**
- フレームの範囲: ステータスバー + ナビ + 本文 + タブバー（オーバーレイがある画面は同じフレームの子に収める）

## セクション

画面はホーム、記帳、書類、証憑、チャット、設定の 6 つのセクションに分ける。

| ルール | 内容 |
| --- | --- |
| 横に置くもの | 同じ画面の上に載る状態だけ（例: 記帳と記帳（メニュー）） |
| 縦に積むもの | 別画面。戻ると前の画面に戻るもの |
| 段の間隔 | 100 程度 |
| セクションの間隔 | 160 程度 |
| 制作メモ | 画面 Frame の外の短いテキスト |

## 画面と node ID

画面ごとの node ID は [画面一覧](../screens/) の対応表を正とする。
