# 書類

見積書、納品書、請求書の共通ルールである。

## 種類

書類は見積書、納品書、請求書の 3 種類とし、一覧の上で切り替える。
切り替えの下に検索を置く。

仕訳を作るのは請求書の発行と入金だけとする。
見積書と納品書は仕訳を作らない。

## メニュー

見積書、納品書、請求書の右上はメニューとする。
項目は、複製、その書類から作れる変換、削除の順とする。
メニューを開いても背景は暗くしない。

## 複製

複製は同じ種類の下書きを作る。
宛先と明細を引き継ぎ、日付は翌月にずらし、番号は新しいものにする。
請求書の複製は発行するまで仕訳を作らない。

## 変換

変換は種類を変える。

| 元 | 先 |
| --- | --- |
| 見積書 | 納品書、請求書 |
| 納品書 | 請求書 |
| 請求書 | 見積書 |

宛先、品名、数量、単価、税率を引き継ぐ。
番号と日付は新しい書類のものにする。
できた書類は下書きとし、請求書は発行するまで仕訳を作らない。

## 見積書

項目は請求書に揃える。
番号は見積番号、期限は有効期限とし、振込先は出さない。

## 納品書

見積書と同じ項目で、日付は納品日とする。
振込先は出さない。

## 請求書の状態

状態は、下書き、未入金、入金済みの 3 つとする。

新規作成で保存すると下書きになる。
下書きは何度でも開いて編集でき、詳細から発行する。

発行を押すとメニューが開く。PDFをダウンロードするか、アプリで共有するかを選ぶ。

税と源泉の詳細は [請求と税](invoice-and-tax.md) を見る。
