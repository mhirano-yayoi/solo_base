# 明細

口座明細の取込と未承認の承認である。

## 取込

明細は貼り付けと CSV を受け付ける。
列は日付・摘要・金額とし、入金はプラス、出金はマイナスとする。

列マッピングは置かない。CSV の列を日付・摘要・金額に固定するためである。

## 未承認の明細

未承認の明細の行は「日付＋摘要」を見出しにし、下の行に選ぶ候補（事業 / 私用 など）を出す。

承認するまで仕訳にしない。

## 承認の結果

| 選び方 | 結果 |
| --- | --- |
| 事業用の出金 | 経費とする |
| 事業用の入金 | 売上か未入金請求の消し込みとする |
| 私用 | 除外か事業主貸とする |

## 入口

記帳の右上メニューから「明細を取り込む」と「未承認の明細」へ進む。
件数バッジは未承認の明細の項目にだけ付ける。

ホームの「未承認の明細」行からも進む。
