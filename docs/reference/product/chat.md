# チャット

チャットの入口、読み取りの範囲、モデルへの渡し方である。

## 入口

入口は下部タブのチャットとする。
どの画面のフッターからでも、チャットの画面を開く。シートにはしない。

画面の左に「履歴」、右に「新規」を置く。
履歴では過去のチャットを開く。新規では会話を開き直す。

入力欄の左にプラスを置く。プラスからファイルを添付できる。

## 読み取りの範囲

チャットは、保存済みの仕訳、明細、書類、証憑、設定について答える。
画面に出しただけの未保存の入力は読まない。

仕訳の登録、書類の発行、入金、削除はチャットから行わない。

## モデルとツール

読み取りは MCP のツールとする。
ツールは画面に依存しない関数を呼ぶ。

答えの文はモデルが作る。
モデルへ渡すのは質問と、ツールが読んだ項目だけとする。台帳は渡さない。

モデルに届かないときは、読んだ件数と金額をそのまま文にして返す。
