# 証憑

証憑の取り込み、確認、仕訳との紐付けである。

## 見本の読み取り

証憑は見本画像を同梱する。

見本を選ぶか、カメラやライブラリで別の写真を撮ると、見本に対応した日付・金額・取引先が入る。
画面に「見本の読み取り」と出す。外部へは送らない。

## 確認画面

確認画面では、取引日、金額、取引先名、区分を保存前に直せる。
新規も編集も同じ画面とする。

証憑の保存はナビの保存で、仕訳の追加や紐付けとは分ける。

確認画面に「仕訳に紐付け」を置く。

| 操作 | 挙動 |
| --- | --- |
| 追加 | かんたん入力で新しい仕訳を作って紐付ける。取引手段は現金とし、あとから仕訳の編集で変えられる |
| 紐付け | 登録済みの仕訳から選ぶ |

選ぶ画面は仕訳の一覧とし、上に検索を置く。
検索は取引日、金額、取引先名とする。

## 紐付け

証憑と仕訳は、どちらからも複数を紐付けられる。
金額の一致は強制せず、差があるときだけ出す。

## 取り込み

保存すると証憑ファイルの取り込みが始まる。
別のアップロード操作は置かず、取り込み前の状態も置かない。
外部へは送らない。

## 一覧の行

一覧の行は、サムネイル、取引先、右端の金額とする。

サムネイルの中央に、取り込み中はくるくる、失敗は印を出す。
成功した行には印を出さない。

日付は年を含め、その横に紐付けの件数を置く。無いときは未紐付けとする。
