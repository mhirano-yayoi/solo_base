# 用語集

項目の名前と、紛らわしい用語の定義である。

## 製品名の対応

項目の名前は、次の製品に合わせる。

| 領域 | 合わせる製品 |
| --- | --- |
| 帳簿と申告の単位 | やよいの青色申告 オンライン |
| 見積書、納品書、請求書 | Misoca |
| 証憑 | 弥生証憑 Next |

## 用語

| 用語 | 定義 |
| --- | --- |
| 区分 | 科目を売上と経費にまとめた選び方。勘定科目の一覧は持たない |
| 取引日 | 仕訳と証憑の日付のラベル |
| 取引手段 | 現金、普通預金、個人。かんたん入力では現金で固定 |
| 集計期間 | 事業所ごとの開始日と終了日。カレンダー月を既定にしない |
| 下書き | 請求書の状態のひとつ。発行前で編集できる |
| 未入金 | 請求書の発行後、入金前の状態 |
| 入金済み | 請求書の入金後の状態 |
| 天引き額 | 入金時に税込合計から差し引く額。初期値は焼き付けた源泉税額 |
| 差引支払額 | 税込合計から源泉税額を引いた額 |
| 見本の読み取り | 同梱の見本画像に対応した日付・金額・取引先を入れること。外部へは送らない |
| 未承認の明細 | 取込後、承認するまでの明細。承認するまで仕訳にしない |
