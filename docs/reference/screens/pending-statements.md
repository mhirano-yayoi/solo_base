# 未承認の明細

取込後、承認前の明細一覧である。

## 画面概要

- **画面の目的**：明細を事業 / 私用などで選び、承認するまで仕訳にしない
- **主な利用者**：デモを触る意思決定者と開発メンバー

[記帳](ledger.md) のメニュー、または [ホーム](home.md) の未承認の行から進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 記帳へ |
| ヘッダー | タイトル | 「未承認の明細」 |
| ヘッダー | 検索 | 検索状態へ |
| 本文 | 行 | 「日付＋摘要」、候補（事業 / 私用、売上 / 消し込み など）、金額（入金は +、出金は −） |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 候補を選ぶ | 行の候補 | 同画面 | 承認すると仕訳になる |
| 検索 | 検索 | 同画面の検索 | 日付、摘要、金額 |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 通常 | 未承認だけ出す |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 通常 | 一覧 |
| 検索 | 検索バー＋キャンセル。Figma `154:147` |
| 空 | 未承認が無い |

## データ・システム挙動

- 事業用の出金は経費、事業用の入金は売上か未入金請求の消し込み、私用は除外か事業主貸
- 承認するまで仕訳にしない

- 行が見出し「日付＋摘要」と候補である
- 検索が日付・摘要・金額である
- 承認前は仕訳に出ない
