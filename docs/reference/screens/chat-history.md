# チャットの履歴

過去のチャットを選ぶ画面である。

## 画面概要

- **画面の目的**：過去の会話タイトルを一覧し、選んで開く
- **主な利用者**：デモを触る意思決定者と開発メンバー

[チャット](chat.md) の「履歴」から進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | タイトル | 「履歴」 |
| 本文 | 会話の行 | タイトル（例: 未入金の確認、11月の利益、ロフトの領収書） |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 行 | タップ | [チャット](chat.md) | その会話を開く |
| 戻る | ジェスチャ / 戻る | [チャット](chat.md) | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 通常 | 過去の会話 |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 一覧 | Figma `95:84` |
| 空 | 会話が無い |

## データ・システム挙動

- 履歴はメモリ上に置く。リロードで消える
