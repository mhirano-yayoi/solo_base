# 見積書

見積書の詳細画面である。

## 画面概要

- **画面の目的**：見積内容を見せ、メニューから複製・変換・削除する
- **主な利用者**：デモを触る意思決定者と開発メンバー

[書類](documents.md) の見積書タブから進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 書類へ |
| ヘッダー | タイトル | 「見積書」 |
| ヘッダー | メニュー | 複製、納品書に変換、請求書に変換、削除 |
| 本文 | 発行者名・登録番号 | 振込先は出さない |
| 本文 | 宛名・見積番号・発行日・有効期限 | |
| 本文 | 明細と税率ごとの税抜・消費税・税込 | |
| 本文 | 源泉税額・差引支払額 | 源泉ありのとき |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 複製 | メニュー | 同じ種類の下書き | 翌月、新しい番号 |
| 納品書に変換 | メニュー | [納品書](delivery-note.md) の下書き | |
| 請求書に変換 | メニュー | [請求書の編集](invoice-edit.md) の下書き | 発行まで仕訳なし |
| 削除 | メニュー | 書類へ | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 通常 | 振込先なし。発行ボタンなし。仕訳を作らない |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 詳細 | Figma `45:2` |
| メニュー | 複製、納品書に変換、請求書に変換、削除。`85:82` |

## データ・システム挙動

- 見積書は仕訳を作らない
- 変換で引き継ぐのは宛先、品名、数量、単価、税率

- 振込先が出ない
- メニュー順が複製、変換、削除である
- メニュー開で背景が暗くならない
