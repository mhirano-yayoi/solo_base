# 記帳

仕訳一覧が本体のタブ画面である。

## 画面概要

- **画面の目的**：仕訳を一覧し、詳細・かんたん入力・明細の取込へ進む
- **主な利用者**：デモを触る意思決定者と開発メンバー

下部タブの「記帳」から開く。別の仕訳一覧画面は置かない。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | タイトル | 「記帳」 |
| ヘッダー | 三点リーダー | メニューを開く |
| ヘッダー | 検索 | 検索バーへ切替 |
| 本文 | 仕訳の行 | 「日付＋取引先」、区分（点マーク＋短い名称）、金額。借方・貸方と摘要は出さない |
| タブ | 下部 5 タブ | ホーム、記帳、書類、証憑、チャット |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 詳細 | 行タップ | [仕訳詳細](journal-detail.md) | |
| かんたん入力 | メニュー | [かんたん入力](quick-entry.md) | |
| 明細を取り込む | メニュー | 取込 UI → [未承認の明細](pending-statements.md) | |
| 未承認の明細 | メニュー | [未承認の明細](pending-statements.md) | 件数バッジはこの項目だけ |
| 検索 | 検索アイコン | 同画面の検索状態 | 取引日、金額、取引先 |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 通常 | 仕訳一覧。スクロールで続きを読み込む |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 通常 | 一覧 |
| メニュー開 | かんたん入力、明細を取り込む、未承認の明細。背景は暗くしない |
| 検索 | 検索バー＋キャンセル。結果は同じ行の形 |
| 空 | 行なし（デモでは初期データあり） |

## データ・システム挙動

- 一覧は保存済みの仕訳だけを出す
- 検索は取引日、金額、取引先

## 受け入れ観点

- 行が「日付＋取引先」と区分である
- メニュー 3 項目があり、未承認だけ件数バッジがある
- メニュー開で背景が暗くならない
- 検索の形が他一覧と同じである
