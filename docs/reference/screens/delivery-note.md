# 納品書

納品書の詳細画面である。

## 画面概要

- **画面の目的**：納品内容を見せ、メニューから複製・変換・削除する
- **主な利用者**：デモを触る意思決定者と開発メンバー

[書類](documents.md) の納品書タブから進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 書類へ |
| ヘッダー | タイトル | 「納品書」 |
| ヘッダー | メニュー | 複製、請求書に変換、削除 |
| 本文 | 発行者名・登録番号 | 振込先は出さない |
| 本文 | 宛名・納品番号・納品日・有効期限 | |
| 本文 | 明細と税率ごとの税抜・消費税・税込 | |
| 本文 | 源泉税額・差引支払額 | 源泉ありのとき |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 複製 | メニュー | 同じ種類の下書き | |
| 請求書に変換 | メニュー | [請求書の編集](invoice-edit.md) の下書き | |
| 削除 | メニュー | 書類へ | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 通常 | 見積書と同じ項目で、日付は納品日。振込先なし |
