# 請求書の作成

新しい請求書の下書きを作る画面である。

## 画面概要

- **画面の目的**：宛名・番号・日付・明細を入れて下書き保存する
- **主な利用者**：デモを触る意思決定者と開発メンバー

[書類](documents.md) の新規から進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 書類へ |
| ヘッダー | タイトル | 「請求書」 |
| ヘッダー | 保存 | 右上 |
| 本文 | 宛名 | 取引先 |
| 本文 | 請求番号 | 例: INV-003 |
| 本文 | 発行日 | カレンダー |
| 本文 | 支払期限 | カレンダー |
| 本文 | 明細行 | 品名、数量 × 単価 · 税率。タップで [品目の入力](line-item-input.md) |
| 本文 | 行を追加 | |
| 本文 | 税抜・消費税・税込 | 税率ごと |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 保存 | 右上 | [書類](documents.md) または詳細 | 下書きになる |
| 品目 | 行 / 行を追加 | [品目の入力](line-item-input.md) | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 通常 | 源泉の基準と端数処理は出さない。設定の既定値で計算 |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 通常 | フォーム |
| 空の明細 | 「行を追加」のみ |

## データ・システム挙動

- 設定の既定値（源泉の基準、端数処理、初期税率）で計算する
- 発行するまで仕訳は作らない

## 受け入れ観点

- 保存がナビ右上である
- 源泉の基準と端数が画面に出ない
- 保存すると下書きになる
