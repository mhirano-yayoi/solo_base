# 仕訳の編集

既存仕訳の編集画面である。

## 画面概要

- **画面の目的**：取引日、金額、取引先、区分、取引手段、摘要を直して保存する
- **主な利用者**：デモを触る意思決定者と開発メンバー

[仕訳詳細](journal-detail.md) の編集から進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 詳細へ戻る |
| ヘッダー | タイトル | 「編集」 |
| ヘッダー | 保存 | 右上 |
| 本文 | 取引日 | カレンダー |
| 本文 | 金額 | 金額入力 |
| 本文 | 取引先 | 一覧から選ぶ |
| 本文 | 区分 | 一覧から選ぶ |
| 本文 | 取引手段 | 現金、普通預金、個人 |
| 本文 | 摘要 | テキスト |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 保存 | 右上 | [仕訳詳細](journal-detail.md) | 借方と貸方が一致する仕訳だけ保存 |
| 戻る | 左 | 詳細 | 未保存は破棄 |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 通常 | 上記項目 |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 通常 | フォーム |
| エラー | 借方と貸方が一致しないときは保存しない |

## データ・システム挙動

- 個人での支出は事業主借、個人での収入は事業主貸とする
- 日付は 2026-01-01 以降だけとする

## 受け入れ観点

- 項目順が取引日、金額、取引先、区分、取引手段、摘要である
- 取引手段を現金・普通預金・個人から選べる
- 保存がナビ右上である

## 実装メモ（Ionic）

- `IonInput` / `IonSelect` / `IonDatetime` / `IonButton`（toolbar slot="end"）
