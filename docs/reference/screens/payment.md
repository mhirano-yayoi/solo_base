# 入金

未入金請求の入金画面である。

## 画面概要

- **画面の目的**：入金日と天引き額を確認して入金仕訳を作る
- **主な利用者**：デモを触る意思決定者と開発メンバー

未入金の [請求書の詳細](invoice-detail.md) から進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 詳細へ |
| ヘッダー | タイトル | 「入金」 |
| ヘッダー | 保存 | 右上 |
| 本文 | 入金日 | カレンダー |
| 本文 | 対象の請求 | 取引先と請求番号 |
| 本文 | 税込 | 税込合計 |
| 本文 | 天引き額 | 初期値は焼き付けた源泉税額。直せる |
| 本文 | 入金額 | 税込合計 − 天引き額 |
| 本文 | 仕訳の内訳 | 借方 普通預金、借方 事業主貸、貸方 売掛金 |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 保存 | 右上 | 請求書の詳細（入金済み） | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 通常 | 上記。一部入金は扱わない |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 通常 | フォーム |

## データ・システム挙動

- 入金の仕訳は、借方 普通預金（入金額）・事業主貸（天引き額）、貸方 売掛金（税込合計）
- 天引き額を直すと入金額が追従する

## 受け入れ観点

- 天引き額を直せ、入金額が税込 − 天引きである
- 事業主貸が入る
- 一部入金ができない

## 実装メモ（Ionic）

- `IonInput`（天引き額） / `IonDatetime` / `IonList`（仕訳内訳の表示）
