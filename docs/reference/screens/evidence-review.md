# 証憑の確認

証憑の項目を直して保存し、仕訳へ紐付ける画面である。

## 画面概要

- **画面の目的**：取引日、金額、取引先名、区分を保存前に直し、仕訳に紐付ける
- **主な利用者**：デモを触る意思決定者と開発メンバー

[証憑の撮影](evidence-capture.md) の使用する、または [証憑](evidence.md) の行から進む。新規も編集も同じ画面とする。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 証憑へ |
| ヘッダー | タイトル | 「証憑」 |
| ヘッダー | 保存 | 右上。仕訳の追加や紐付けとは分ける |
| 本文 | 見本の読み取り | ラベル。外部へ送らない旨の表示 |
| 本文 | 取引日 | カレンダー |
| 本文 | 金額 | |
| 本文 | 取引先名 | |
| 本文 | 区分 | |
| 本文 | 仕訳に紐付け | 追加、紐付け。紐付け済みなら仕訳行の一覧 |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 保存 | 右上 | [証憑](evidence.md) | 取り込み開始 |
| 追加 | 仕訳に紐付けの追加 | [かんたん入力](quick-entry.md) | 新しい仕訳を作って紐付け。取引手段は現金 |
| 紐付け | 仕訳に紐付けの紐付け | [仕訳に紐付け](evidence-link-journal.md) | 登録済みの仕訳から選ぶ |
| 仕訳行 | 紐付け済みの行 | [仕訳詳細ダイアログ](journal-dialog.md) | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 未紐付け | 追加・紐付けのみ |
| 紐付け済み | 仕訳行（日付・取引先・金額・区分）と追加・紐付け |
