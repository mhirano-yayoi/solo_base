# 証憑に紐付け

仕訳詳細から、登録済みの証憑を選んで紐付ける画面である。

## 画面概要

- **画面の目的**：証憑一覧から複数を選び、現在の仕訳へ紐付ける
- **主な利用者**：デモを触る意思決定者と開発メンバー

[仕訳詳細](journal-detail.md) の「紐付け」から進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 詳細へ |
| ヘッダー | タイトル | 「証憑に紐付け」 |
| ヘッダー | 保存 | 右上 |
| 本文 | 証憑の行 | 取引先、日付、金額。選択中は ✓ |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 選択 | 行タップ | 同画面 | 複数可 |
| 保存 | 右上 | [仕訳詳細](journal-detail.md) | 紐付けを確定 |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 通常 | 登録済みの証憑 |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 通常 | 選択リスト |
| 空 | 証憑が無い |

## データ・システム挙動

- 金額の一致は強制せず、差があるときだけ出す
- 証憑と仕訳は複数を紐付けられる
