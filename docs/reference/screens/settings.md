# 設定

アプリ全体の設定画面である。

## 画面概要

- **画面の目的**：事業者、取引先、税率、源泉、端数、未実装、デモに戻すを置く
- **主な利用者**：デモを触る意思決定者と開発メンバー

[ホーム](home.md) 右上のアイコンだけから開く。下部タブには置かない。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | ホームへ |
| ヘッダー | タイトル | 「設定」 |
| 本文 | 事業者 | 集計期間の決め方を含む |
| 本文 | 取引先 | 源泉の有無と請求の型 |
| 本文 | 新しい請求の初期税率 | 例: 10% |
| 本文 | 源泉の基準 | 税抜 / 税込。既定は税抜 |
| 本文 | 消費税の端数 | 切捨て / 四捨五入 / 切上げ。既定は切捨て |
| 本文 | 未実装の機能 | [未実装の機能](unimplemented-features.md) へ。初期オフ |
| 本文 | デモに戻す | 初期データに戻す |
| タブ | 下部 5 タブ | 設定自体はタブではないが、フッターは残る |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 未実装の機能 | 行 | [未実装の機能](unimplemented-features.md) | オンのとき一覧と理由 |
| デモに戻す | 行 | 確認後ホーム | 初期データに戻る |
