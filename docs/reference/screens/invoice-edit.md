# 請求書の編集

下書き請求書の編集画面である。

## 画面概要

- **画面の目的**：下書きの項目を直し、この請求書だけの源泉の基準と端数を上書きできる
- **主な利用者**：デモを触る意思決定者と開発メンバー

下書きの請求から進む。発行後は開けない。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 前の画面へ |
| ヘッダー | タイトル | 「編集」 |
| ヘッダー | 保存 | 右上 |
| 本文 | 宛名・請求番号・発行日・支払期限 | 作成と同じ |
| 本文 | 明細行・行を追加 | [品目の入力](line-item-input.md) |
| 本文 | 税抜・消費税・税込 | |
| 本文 | 源泉の基準 | 税抜 / 税込。この請求書だけ上書き |
| 本文 | 消費税の端数 | 切捨て / 四捨五入 / 切上げ |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 保存 | 右上 | [請求書の詳細](invoice-detail.md) または一覧 | |
| 品目 | 行 | [品目の入力](line-item-input.md) | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 下書き | 編集可。発行ボタンは置かない |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 通常 | フォーム＋源泉・端数の上書き |

## データ・システム挙動

- 新規作成画面と違い、源泉の基準と端数処理を出せる
- 発行するまで仕訳は作らない
