# 請求書の詳細

請求書の閲覧・発行・メニュー操作の画面である。

## 画面概要

- **画面の目的**：請求内容を見せ、下書きなら発行し、メニューから複製・変換・削除する
- **主な利用者**：デモを触る意思決定者と開発メンバー

[書類](documents.md) の行から進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 書類へ |
| ヘッダー | タイトル | 「請求書」 |
| ヘッダー | メニュー | 複製、見積書に変換、削除 |
| 本文 | 発行者名・登録番号・振込先 | |
| 本文 | 宛名・請求番号・取引年月日・支払期限 | |
| 本文 | 明細行 | 税率・数量 × 単価 |
| 本文 | 税率ごとの税抜・消費税・税込 | |
| 本文 | 源泉税額・差引支払額 | 源泉ありのとき |
| フッター上 | 発行 | 下部タブのすぐ上に固定。下書きのとき |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 発行 | 発行ボタン | 発行メニュー | PDFをダウンロード / アプリで共有。背景は暗くしない |
| 複製 | メニュー | 下書きの新規 | 翌月、新しい番号 |
| 見積書に変換 | メニュー | [見積書](quote.md) の下書き | |
| 削除 | メニュー | 書類へ | 書類だけ消す |
| 入金 | 未入金のとき | [入金](payment.md) | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 下書き | 発行ボタンあり。編集可能（編集画面へ） |
| 発行後（未入金） | 焼き付け済み。編集しない。入金へ進める |
| 入金済み | 発行・入金なし |

## データ・システム挙動

- 発行すると行の税率と金額、源泉の対象額と税額を焼き付け、借方 売掛金・貸方 売上を税込合計 1 本作る
- 以後は編集しない

## 受け入れ観点

- 発行が下部タブのすぐ上にある
- 発行メニューで PDF / 共有を選べ、背景が暗くならない
- メニューで複製・変換・削除ができる

## 実装メモ（Ionic）

- `IonFooter` 内の発行ボタン（タブの上） / `IonActionSheet` または `IonPopover`（オーバーレイなし）
