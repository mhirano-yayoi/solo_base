# 未実装の機能

デバッグ用に、今回作っていない機能の一覧と理由を出す画面である。

## 画面概要

- **画面の目的**：範囲外の機能名と理由を見せる。動くフォームは置かない
- **主な利用者**：社内の意思決定者と開発メンバー

[設定](settings.md) の「未実装の機能」から進む。初期オフとし、オンのときだけ内容を出す。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 設定へ |
| ヘッダー | タイトル | 「未実装の機能」 |
| 本文 | 機能名と理由の行 | 一覧 |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 戻る | 左 | [設定](settings.md) | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| オフ | 設定のトグルのみ。この画面の中身は出さないか空 |
| オン | 下表を出す |

## データ・システム挙動

一覧と理由の正は [概要](../product/overview.md) の「範囲外（未実装）」である。

| 機能 | 理由 |
| --- | --- |
| e-Tax 送信 | データを外部へ送らないため |
| 確定申告書 | 申告書の作成は今回の範囲外のため |
| 銀行 API | 外部サーバーと連携しないため |
| 列マッピング | CSV の列を日付・摘要・金額に固定するため |
| 帳票と決算書 | 仕訳帳・元帳・試算表を作らないため |
| 源泉の年間一覧 | 年間の集計は申告の範囲のため |
| 100 万円超の源泉 | デモの請求は税込 100 万円以下のため |
| 証憑の解像度チェックとタイムスタンプ | 見本の読み取りだけを置くため |
| 在庫 | 在庫を持たない業種を対象にするため |
| 部門 | 一人事業で部門を分けないため |
| 給与 | 従業員を雇わないため |
| 法人税 | 個人事業主を対象にするため |
