# チャット

下部タブのチャット画面である。

## 画面概要

- **画面の目的**：保存済みのデータについて質問し、答えを見る
- **主な利用者**：デモを触る意思決定者と開発メンバー

どの画面のフッターからでも開く。シートにはしない。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 履歴 | 左。[チャットの履歴](chat-history.md) へ |
| ヘッダー | 新規 | 右。会話を開き直す |
| 本文 | メッセージ | 質問と答えの吹き出し |
| 入力 | プラス | 左。ファイル添付 |
| 入力 | 質問を書く | テキスト |
| 入力 | 送る | |
| タブ | 下部 5 タブ | チャットが選択中 |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 履歴 | 左 | [チャットの履歴](chat-history.md) | |
| 新規 | 右 | 同画面 | 会話を開き直す |
| 添付 | プラス | ファイル選択 | |
| 送る | 送る | 同画面 | ツールで読み、モデルが答える |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 通常 | 会話 |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 会話中 | Figma `95:3` |

## データ・システム挙動

- 保存済みの仕訳、明細、書類、証憑、設定だけ読む
- 登録、発行、入金、削除はしない
- モデルに届かないときは件数と金額を文にして返す
