# かんたん入力

新しい仕訳を手早く入れる画面である。

## 画面概要

- **画面の目的**：取引日、金額、取引先、区分、取引手段、摘要を入れて保存する
- **主な利用者**：デモを触る意思決定者と開発メンバー

[記帳](ledger.md) のメニュー、または証憑の確認の「追加」から進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 前の画面へ |
| ヘッダー | タイトル | 「かんたん入力」 |
| ヘッダー | 保存 | 右上 |
| 本文 | 取引日 | カレンダー。例: 2026/11/17 |
| 本文 | 金額 | 金額入力 |
| 本文 | 取引先 | 一覧から選ぶ |
| 本文 | 区分 | 例: 経費 |
| 本文 | 取引手段 | 「現金」。選び直せない |
| 本文 | 摘要 | テキスト |
| 本文 | 続けて入力 | トグル。項目の下 |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 保存（続けて入力オフ） | 右上 | [記帳](ledger.md) | |
| 保存（続けて入力オン） | 右上 | 同画面 | フォームを残す |
| 戻る | 左 | 前の画面 | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 通常 | 取引手段は現金で固定。見出しの下に値を置く |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 通常 | フォーム |
| エラー | 借方と貸方が一致しないときは保存しない |

## データ・システム挙動

- 保存時に借方と貸方が一致する仕訳を 1 本作る
- 証憑の「追加」から来たときは、保存した仕訳をその証憑へ紐付ける

## 受け入れ観点

- 取引手段が現金で変えられない
- 「続けて入力」が項目の下にある
- 保存がナビ右上である
