# 仕訳に紐付け

証憑の確認から、登録済みの仕訳を選んで紐付ける画面である。

## 画面概要

- **画面の目的**：仕訳一覧から選び、現在の証憑へ紐付ける
- **主な利用者**：デモを触る意思決定者と開発メンバー

[証憑の確認](evidence-review.md) の「紐付け」から進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 確認へ |
| ヘッダー | タイトル | 「仕訳に紐付け」 |
| ヘッダー | 保存 | 右上 |
| ヘッダー | 検索 | 検索状態へ |
| 本文 | 仕訳の行 | 「日付＋取引先」、区分、金額。記帳と同じ形 |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 選択 | 行 | 同画面 | 複数可 |
| 保存 | 右上 | [証憑の確認](evidence-review.md) | |
| 検索 | 検索 | 同画面の検索 | 取引日、金額、取引先名 |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 通常 | 登録済みの仕訳 |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 通常 | Figma `31:320` |
| 検索 | Figma `154:332` |

## データ・システム挙動

- 検索は取引日、金額、取引先名
- 複数を紐付けられる
