# 証憑の撮影

カメラまたはライブラリから証憑画像を取る画面である。

## 画面概要

- **画面の目的**：見本または写真を選び、確認画面へ渡す
- **主な利用者**：デモを触る意思決定者と開発メンバー

[証憑](evidence.md) の撮影から進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | キャンセル | 証憑一覧へ |
| 本文 | 枠と案内 | 「書類を枠に合わせてください」 |
| 本文 | アルバム | ライブラリ |
| 本文 | ファイル | ファイル選択 |

撮影後の確認:

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 撮り直す | 撮影へ戻る |
| ヘッダー | 使用する | [証憑の確認](evidence-review.md) へ |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| キャンセル | 左 | [証憑](evidence.md) | |
| アルバム / ファイル | 下部 | 撮影後 | 見本に対応した値が入る |
| 使用する | 右 | [証憑の確認](evidence-review.md) | 「見本の読み取り」 |
| 撮り直す | 左 | 撮影 | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 撮影 | 枠と案内 |
| 撮影後 | プレビュー |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 撮影 | Figma `160:24` |
| 撮影後 | Figma `160:43` |

## データ・システム挙動

- 見本を選ぶか別の写真を撮ると、見本に対応した日付・金額・取引先が入る
- 外部へは送らない
