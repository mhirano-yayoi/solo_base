# 証憑

証憑一覧のタブ画面である。

## 画面概要

- **画面の目的**：証憑を一覧し、撮影と確認へ進む
- **主な利用者**：デモを触る意思決定者と開発メンバー

下部タブの「証憑」から開く。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | タイトル | 「証憑」 |
| ヘッダー | 撮影 | [証憑の撮影](evidence-capture.md) へ |
| ヘッダー | 検索 | 検索状態へ |
| 本文 | 行 | サムネイル、取引先、日付（年を含む）、紐付け件数または未紐付け、右端の金額 |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 撮影 | 右上 | [証憑の撮影](evidence-capture.md) | |
| 行 | タップ | [証憑の確認](evidence-review.md) | |
| 検索 | 検索 | 同画面の検索 | 取引日、金額、取引先 |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 取り込み中 | サムネ中央にくるくる |
| 失敗 | サムネ中央に印（!） |
| 成功 | 印なし |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 通常 | 一覧 |
| 検索 | Figma `154:254` |

## データ・システム挙動

- 保存すると取り込みが始まる。取り込み前の状態は置かない
- 外部へは送らない

## 受け入れ観点

- 行がサムネ・取引先・日付・紐付け・金額である
- 取り込み中と失敗の印が出る
- 検索が取引日・金額・取引先である
