# 品目の入力

請求書などの明細 1 行を入れる画面である。

## 画面概要

- **画面の目的**：品名、数量、単価、税率を入れて保存する
- **主な利用者**：デモを触る意思決定者と開発メンバー

[請求書の作成](invoice-create.md) または [請求書の編集](invoice-edit.md) の行から進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 作成・編集へ |
| ヘッダー | タイトル | 「品目」 |
| ヘッダー | 保存 | 右上 |
| 本文 | 品目名 | テキスト |
| 本文 | 数量 | 数値。時間単価は時間、月額は 1 |
| 本文 | 単価 | 税込 |
| 本文 | 税率 | 10% または 8% |
| 本文 | この品目を削除 | 既存行のとき |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 保存 | 右上 | 作成・編集 | |
| 削除 | 「この品目を削除」 | 作成・編集 | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 8% | 親画面側で軽減税率の旨を出す |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 新規 | 削除なし |
| 既存 | 削除あり |

## データ・システム挙動

- 行の金額は税込で入れる
- 初期税率は設定の「新しい請求の初期税率」
