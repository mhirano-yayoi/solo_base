# 書類

見積書・納品書・請求書の一覧画面である。

## 画面概要

- **画面の目的**：書類の種類を切り替え、一覧から詳細・作成へ進む
- **主な利用者**：デモを触る意思決定者と開発メンバー

下部タブの「書類」から開く。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | タイトル | 「書類」 |
| ヘッダー | 新規 | 請求書の作成などへ |
| ヘッダー | 検索 | 検索状態へ |
| 本文 | 種類切替 | 請求書、見積書、納品書 |
| 本文 | 検索 | 切り替えの下（検索状態では上部バー） |
| 本文 | 行 | 取引先、番号・期限、金額、状態（下書き / 未入金 / 入金済み） |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 種類切替 | セグメント | 同画面 | 一覧を差し替える |
| 行（請求書） | タップ | [請求書の詳細](invoice-detail.md) または [請求書の編集](invoice-edit.md) | 下書きは編集、発行後は詳細 |
| 行（見積書） | タップ | [見積書](quote.md) | |
| 行（納品書） | タップ | [納品書](delivery-note.md) | |
| 新規 | 右上 | [請求書の作成](invoice-create.md) | 選択中の種類に合わせる |
| 検索 | 検索 | 同画面の検索 | 取引先、番号、金額 |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 請求書 | 状態バッジ付きの行 |
| 見積書・納品書 | 同形の行 |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 通常 | 一覧 |

## データ・システム挙動
