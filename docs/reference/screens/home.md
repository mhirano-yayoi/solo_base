# ホーム

ホームタブの画面である。

## 画面概要

- **画面の目的**：集計期間の売上・経費・利益と、未処理の件数を見せ、各タブへ進ませる
- **主な利用者**：デモを触る意思決定者と開発メンバー

下部タブの「ホーム」から開く。設定は右上のアイコンだけから開く。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 見出し | 事業者名（例: デモ事業） |
| ヘッダー | 設定アイコン | 右上。文言は付けない。[設定](settings.md) へ |
| 本文 | 集計期間 | 開始日と終了日（例: 10/21 – 11/20）。「今月」とは書かない |
| 本文 | 売上・経費・利益 | 3 列。その集計期間の金額 |
| 本文 | 未承認の明細 | 件数と「タップで記帳へ」。[未承認の明細](pending-statements.md) へ |
| 本文 | 未入金の請求 | 件数と「タップで書類へ」。[書類](documents.md) へ |
| 本文 | 未紐付けの証憑 | 件数と「タップで証憑へ」。[証憑](evidence.md) へ |
| タブ | 下部 5 タブ | ホーム、記帳、書類、証憑、チャット |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 設定を開く | 右上アイコン | [設定](settings.md) | |
| 未承認へ | 未承認の明細の行 | [未承認の明細](pending-statements.md) | |
| 書類へ | 未入金の請求の行 | [書類](documents.md) | |
| 証憑へ | 未紐付けの証憑の行 | [証憑](evidence.md) | |
| タブ切替 | 下部タブ | 各タブ | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 通常 | 上記を表示 |
| 件数が 0 | 行は出して件数 0 とする |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 通常 | 集計と未処理の行 |
| 空 | 該当なし（デモ初期データがある） |
| 読込中 | 該当なし（状態はメモリ上で即時） |
| エラー | 該当なし |

## データ・システム挙動

- 集計期間は事業所ごとに持ち、設定の事業者で変える。カレンダー月を既定にはしない
- 月の切替は置かない

## 受け入れ観点

- 見出しが事業者名である
- 集計期間が開始日–終了日で出る
- 売上・経費・利益が出る
- 未処理 3 行から各タブへ進める
- 設定は右上アイコンのみで、タブにない

## 実装メモ（Ionic）

- `IonPage` / `IonHeader` / `IonContent` / `IonTabBar`
- 設定は `IonButton`（icon-only）で `IonIcon`（settingsOutline）
