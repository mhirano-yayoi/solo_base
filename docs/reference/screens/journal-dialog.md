# 仕訳詳細ダイアログ

証憑の確認から、紐付いた仕訳をシートで見る画面である。

## 画面概要

- **画面の目的**：紐付いた仕訳の概要を、確認画面の上に出して閉じられるようにする
- **主な利用者**：デモを触る意思決定者と開発メンバー

[証憑の確認](evidence-review.md) の紐付け済み仕訳行から進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| シート | タイトル | 「仕訳詳細」 |
| シート | 閉じる | |
| シート | 取引日、金額、区分、取引手段、摘要 | |
| シート | 借方・貸方 | |
| 背景 | 確認画面 | 薄く見える |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 閉じる | 閉じる | [証憑の確認](evidence-review.md) | |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 紐付け済み行があるとき | 開ける |
