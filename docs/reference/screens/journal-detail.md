# 仕訳詳細

仕訳の閲覧画面である。

## 画面概要

- **画面の目的**：1 本の仕訳を閲覧し、編集・削除・証憑の紐付けへ進む
- **主な利用者**：デモを触る意思決定者と開発メンバー

[記帳](ledger.md) の行から進む。

## 画面構成

| 領域 | 要素 | 役割・表示条件 |
| --- | --- | --- |
| ヘッダー | 戻る | 記帳へ戻る |
| ヘッダー | タイトル | 「仕訳詳細」 |
| ヘッダー | 編集 | [仕訳の編集](journal-edit.md) へ |
| 本文 | 取引先 | 見出し相当 |
| 本文 | 取引日、金額、区分、取引手段、摘要 | 閲覧 |
| 本文 | 借方・貸方の仕訳行 | 科目と金額 |
| 本文 | 証憑 | 紐付け一覧、追加、紐付け、外す |
| 本文 | この仕訳を削除 | 下部 |
| タブ | 下部 5 タブ | |

## 主要アクションと遷移

| アクション | きっかけ | 遷移先 | 補足 |
| --- | --- | --- | --- |
| 編集 | 右上 | [仕訳の編集](journal-edit.md) | |
| 削除 | 「この仕訳を削除」 | 記帳へ | 確認は必要に応じて |
| 追加 | 証憑の追加 | [証憑の撮影](evidence-capture.md) → [証憑の確認](evidence-review.md) | 新しい証憑を作ってこの仕訳へ紐付ける |
| 紐付け | 証憑の紐付け | [証憑に紐付け](journal-link-evidence.md) | 登録済みの証憑から選ぶ |
| 外す | 紐付け行の外す | 確認ダイアログ | 「証憑を外しますか？」 |

## 表示条件

| 条件 | 表示・挙動 |
| --- | --- |
| 証憑なし | 証憑セクションに追加・紐付けのみ |
| 証憑あり | 紐付け行（日付 · 金額）と外す |

## 状態

| 状態 | 見え方・挙動 |
| --- | --- |
| 証憑なし | Figma `162:24` |
| 証憑あり | Figma `162:73` |
| 外す確認 | ダイアログ「証憑を外しますか？」。どちらも削除されない。Figma `165:71` |

## データ・システム挙動

- 証憑と仕訳は複数を紐付けられる
- 外すと紐付けだけ解除し、証憑も仕訳も削除しない

## 受け入れ観点

- 借方・貸方の行が出る
- 編集と削除ができる
- 証憑の追加・紐付け・外すができる
- 外す確認で削除はしない

## 実装メモ（Ionic）

- `IonBackButton` / `IonButton` / `IonList` / `IonAlert`（外す確認）
