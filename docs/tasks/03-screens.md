# 03 画面

- [ ] 未着手

## 目的

ホーム、記帳、書類、証憑と設定を、ドメインへ接続する。

## 依存

[02 ドメインと保存](02-domain-and-storage.md) が終わっていること。

## 完了条件

- [ ] 下部タブがホーム、記帳、書類、証憑、チャットの 5 つで、設定はホーム右上のアイコンから開く
- [ ] どの画面のフッターからでもチャットの画面を開ける
- [ ] チャットの左に履歴、右に新規がある。入力欄の左に添付のプラスがある
- [ ] チャットは保存済みのデータを読んで答え、登録、発行、入金、削除はできない
- [ ] ホームの見出しが事業者名で、集計期間の開始日と終了日、その期間の売上・経費・利益が出る
- [ ] ホームに未承認明細、未入金請求、未紐付け証憑の件数が出て、各タブへ進める
- [ ] 入力画面の保存がナビの右上にある
- [ ] 記帳でかんたん入力ができ、仕訳詳細から編集と削除ができる
- [ ] かんたん入力の取引手段は現金のままで、仕訳の編集では現金、普通預金、個人に変えられる
- [ ] 明細を貼り付けと CSV（日付・摘要・金額）で取り込み、未承認の行が「日付＋摘要」で出る
- [ ] 承認するまで仕訳にならない
- [ ] 書類で見積書、納品書、請求書を切り替えられる
- [ ] 見積書、納品書、請求書を複製すると、同じ種類の翌月の下書きになる
- [ ] 変換は種類を変えるだけで、見積書から納品書と請求書、納品書から請求書、請求書から見積書を作れる
- [ ] 請求書が下書き、未入金、入金済みの状態を持ち、下書きを編集でき、詳細の下部に固定した発行から出せる
- [ ] 発行を押すと、PDFをダウンロードするかアプリで共有するかを選べる
- [ ] 請求書に発行者名、登録番号、振込先、宛名、請求番号、取引年月日、支払期限、税率ごとの税抜・消費税・税込が出る
- [ ] 明細行が税率 10% か 8% を持ち、8% の行に軽減税率の旨が出る
- [ ] 新規作成は設定の既定値（源泉の基準、端数処理）で計算し、下書きの編集で請求書ごとに上書きできる
- [ ] 発行の仕訳が売掛金と売上の税込合計 1 本で、行税率と金額、源泉の対象額と税額を焼き付ける
- [ ] 入金画面に入金日、天引き額、入金額が出て、事業主貸を計上する
- [ ] 証憑で見本の読み取りができ、画面に「見本の読み取り」と出る
- [ ] 証憑の確認は取引日、金額、取引先名、区分で、保存はナビの保存である
- [ ] 確認の「仕訳に紐付け」で、追加はかんたん入力の新しい仕訳、紐付けは登録済みの仕訳から選ぶ
- [ ] 記帳、書類、証憑、未承認の明細、仕訳の選択に、同じ形の検索がある
- [ ] 設定で事業者、取引先、初期税率、源泉の基準、消費税の端数、未実装の機能、デモに戻すが使える
- [ ] 未実装の機能は初期オフで、オンにすると一覧と理由が出る
- [ ] Ionic のコンポーネントと CSS 変数だけを使っている
