# 05 ホーム

- [x] 完了

## 目的

ホームタブに集計と未処理の件数を出し、設定と各タブへの導線を置く。

## 依存

[04 デモデータと状態](04-state.md) が終わっていること。

## 完了条件

- [x] ホームの見出しが事業者名である
- [x] 集計期間の開始日と終了日、その期間の売上・経費・利益が出る
- [x] ホームに未承認明細、未入金請求、未紐付け証憑の件数が出て、各タブへ進める
- [x] 設定はホーム右上のアイコンだけから開く（文言は付けない）。この作業では設定画面は空でよい

## 確認の仕方

- `npm run dev` でホームを開き、見出し・集計・件数 3 行が出ること
- 件数 3 行をタップすると、それぞれ記帳（未承認）・書類・証憑へ進むこと（遷移先が未実装なら空画面でも可）

## この作業ではやらないこと

- 設定の中身（[06 設定](06-settings.md)）
- 記帳・書類・証憑の本実装
