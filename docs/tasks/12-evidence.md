# 12 証憑

- [x] 完了

## 目的

証憑の一覧、撮影・添付、確認、仕訳への紐付けを使えるようにする。

## 依存

[07 記帳](07-ledger.md) が終わっていること。

## 完了条件

- [x] 証憑で見本の読み取りができ、画面に「見本の読み取り」と出る
- [x] 撮影・添付は `<input type="file" accept="image/*" capture="environment">` で行い、プレビューは objectURL のみ。どこにも送らない
- [x] 公開デモのため「実在の書類は入れない」と画面に出す
- [x] 証憑の確認は取引日、金額、取引先名、区分で、保存はナビの保存である
- [x] 確認の「仕訳に紐付け」で、追加はかんたん入力の新しい仕訳、紐付けは登録済みの仕訳から選ぶ
- [x] 証憑を保存しても、それだけでは仕訳はできない

## 確認の仕方

- 見本を選ぶと日付・金額・取引先が入り、保存前に直せるること
- 「追加」からかんたん入力で仕訳を作って紐付けられること
- 「紐付け」で登録済みの仕訳を選べること

## この作業ではやらないこと

- 解像度チェックとタイムスタンプ
- 検索（[14](14-search.md)）
