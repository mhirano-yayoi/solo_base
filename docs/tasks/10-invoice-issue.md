# 10 請求書の発行と入金

- [x] 完了

## 目的

請求書の詳細から発行と入金ができ、仕訳が作られるようにする。

## 依存

[09 請求書の作成と編集](09-invoice-create.md) と [07 記帳](07-ledger.md) が終わっていること。

## 完了条件

- [x] 詳細の下部に固定した発行から出せる
- [x] 発行を押すと、PDFをダウンロードするかアプリで共有するかを選べる
- [x] 発行の仕訳が売掛金と売上の税込合計 1 本で、行税率と金額、源泉の対象額と税額を焼き付ける
- [x] 入金画面に入金日、天引き額、入金額が出て、事業主貸を計上する
- [x] 発行後は下書きから未入金になり、入金後は入金済みになる

## 確認の仕方

- 下書きを発行し、記帳に売掛金・売上の仕訳が 1 本増えること
- 入金すると普通預金・事業主貸・売掛金の仕訳ができ、状態が入金済みになること
- 発行メニューで PDF のダウンロードか共有を選べること

## この作業ではやらないこと

- 見積書・納品書（[11](11-quote-delivery.md)）
- 一部入金
