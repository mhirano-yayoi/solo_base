# 02 ドメインと保存

- [ ] 未着手

## 目的

Ionic React + Vite の土台を置き、仕訳・税・源泉の純関数と IndexedDB、デモの初期データを先に作る。

## 依存

[01 Figma ワイヤー](01-figma-wireframes.md) が終わっていることが望ましい。画面構成の確認後に着手する。

## 完了条件

- [ ] Vite + Ionic React（`@ionic/react` 9.0.11）のプロジェクトが起動する
- [ ] 起動時の 1 箇所で iOS モードを固定している
- [ ] Capacitor を入れてない
- [ ] `src/domain` に仕訳・税・源泉の純関数があり、Ionic に依存していない
- [ ] 源泉の基準（税抜・税込）と消費税の端数処理を、既定値と請求書ごとの上書きで切り替えて計算できる
- [ ] かんたん入力の取引手段の既定が現金で、仕訳では現金、普通預金、個人に変えられる
- [ ] 借方と貸方が一致しない仕訳を保存できない
- [ ] 科目が固定である（現金、普通預金、売掛金、売上、主な経費、事業主貸、事業主借）
- [ ] 日付が 2026-01-01 以降だけである
- [ ] Dexie 4.4.7 で IndexedDB に保存している
- [ ] デモの初期データがある（月額顧問の法人、時間単価の法人、下書き・未入金・入金済みの請求書、紐付け済みと未紐付けの証憑）
- [ ] 「デモに戻す」で初期データに戻せる
- [ ] チャットが読む件数と集計を、画面に依存しない関数で返す

## この作業ではやらないこと

- 画面の実装
- ブラウザでの操作確認の完了報告
- Material モードの切り替え UI
- 科目マスタ、仕訳帳、元帳、試算表
