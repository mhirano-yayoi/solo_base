# 07 記帳

- [x] 完了

## 目的

記帳タブで仕訳の一覧・詳細・編集・削除・かんたん入力を使えるようにする。

## 依存

[04 デモデータと状態](04-state.md) が終わっていること。

## 完了条件

- [x] 記帳でかんたん入力ができ、仕訳詳細から編集と削除ができる
- [x] かんたん入力の取引手段は現金のままで、仕訳の編集では現金、普通預金、個人に変えられる
- [x] 入力画面の保存がナビの右上にある
- [x] 借方と貸方が一致しない仕訳を保存できない
- [x] 記帳の右上メニューに、かんたん入力・明細の取込・未承認の明細がある（後者 2 つはこの作業では空画面への導線でよい）

## 確認の仕方

- `npm run dev` で記帳を開き、一覧から詳細・編集・削除ができること
- かんたん入力で仕訳を追加し、一覧に出ること

## この作業ではやらないこと

- 明細の取込と承認の本実装（[08](08-import.md)）
- 検索（[14](14-search.md)）
