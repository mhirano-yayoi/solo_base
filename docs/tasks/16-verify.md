# 16 操作確認

- [x] 完了

## 目的

ブラウザで主要フローを操作し、台本外でも動くことを確認する。

## 依存

[15 PWA と公開](15-pwa-publish.md) が終わっていること（ローカル確認だけ先にしてもよい）。

## 完了条件

- [x] 明細を取り込み、事業用と私用を選んで承認できる
- [x] 請求書の 1 行を 8% に変え、税額が税率ごとに 2 行へ分かれる
- [x] 請求書を下書きで保存し、編集で源泉の基準と端数処理を上書きしてから、詳細の下部で発行できる
- [x] 発行では PDF のダウンロードかアプリでの共有を選べる
- [x] 源泉ありの請求を発行し、売掛金と売上の仕訳が税込合計で 1 本になる
- [x] 入金の消し込みで事業主貸が入り、天引き額を直せる
- [x] 見本の読み取りで日付・金額・取引先が入り、保存前に直せる
- [x] 請求書を複製すると翌月の下書きになり、見積書への変換とは別の操作である
- [x] 証憑を保存しても、それだけでは仕訳はできない
- [x] 証憑の「追加」からかんたん入力で仕訳を作って紐付けられる
- [x] 証憑の「紐付け」で、検索した登録済みの仕訳を選べる
- [x] 「デモに戻す」で初期データに戻る
- [x] 未実装の機能をオンにすると、一覧と理由が出る
- [x] フッターのチャットを開くと専用の画面になる
- [x] 履歴から過去のチャットを開け、新規で会話を開き直せる
- [x] 入力欄の左に添付のプラスがある
- [x] 未入金の件数を聞くと、ホームの件数と一致する
- [x] 確認結果のメモを、この文書か `docs/` 内に残している

## 確認の仕方

- 上の完了条件をブラウザで順に操作する
- 公開 URL でも主要フローが動くこと

## この作業ではやらないこと

- 新しい機能の追加
- 方針の変更（変更が必要なら [../reference/](../reference/) を書き換える）
- 本番向けの性能計測や暗号化
