# 08 明細の取込と承認

- [x] 完了

## 目的

明細を貼り付けと CSV で取り込み、未承認の行を承認して仕訳にする。

## 依存

[07 記帳](07-ledger.md) が終わっていること。

## 完了条件

- [x] 明細を貼り付けと CSV（日付・摘要・金額）で取り込み、未承認の行が「日付＋摘要」で出る
- [x] 承認するまで仕訳にならない
- [x] 事業用と私用を選んで承認できる
- [x] ホームと記帳メニューから未承認の明細へ進める

## 確認の仕方

- CSV か貼り付けで明細を取り込み、未承認一覧に出ること
- 承認すると仕訳一覧に増え、未承認から消えること
