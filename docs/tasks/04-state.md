# 04 デモデータと状態

- [x] 完了

## 目的

デモの初期データをメモリ上のストアに置き、「デモに戻す」と件数・集計の読み取り関数を用意する。

## 依存

[03 ドメイン](03-domain.md) が終わっていること。

## 完了条件

- [x] 状態はメモリ上にあり、Dexie / IndexedDB を使っていない
- [x] デモの初期データがある（月額顧問の法人、時間単価の法人、下書き・未入金・入金済みの請求書、紐付け済みと未紐付けの証憑）
- [x] 「デモに戻す」で初期データに戻せる
- [x] チャットが読む件数と集計を、画面に依存しない関数で返す
- [x] リロードするとデモの初期データに戻る

## 確認の仕方

- `npm test` でストアと読み取り関数のテストが通ること
- デモデータの件数・金額が [デモデータ](../reference/product/demo-data.md) の方針と矛盾しないこと

## この作業ではやらないこと

- 画面の実装
- JSON の書き出し・読み込み
- 永続化
