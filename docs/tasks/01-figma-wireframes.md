# 01 Figma ワイヤー

- [ ] 未着手

## 目的

モバイル幅の低忠実度ワイヤーで、画面の構成を共有できる形にする。
プロトタイプの遷移は作らない。画面どうしの関係は、キャンバスの並びで示す。

## 依存

なし。最初に着手してよい。

## 完了条件

- [x] ホームがモバイル幅で置いてある（見出しは事業者名、集計期間の開始日–終了日と売上・経費・利益、未承認明細、未入金請求、未紐付け証憑、下部5タブ、設定は右上アイコンのみ）
- [x] チャットはフッターの専用画面で、左に履歴、右に新規、入力の左に添付のプラスがある。履歴は別画面である
- [x] 記帳、書類、証憑、設定の画面がモバイル幅で並んでいる
- [x] セクション 6 つに分かれ、同じ画面の状態は横、別画面は縦に並んでいる
- [x] 入力画面の保存がナビの右上にある
- [x] 未決の項目（画面外メモ）が決まり、ワイヤーに反映されている
- [x] ワイヤーのリンクまたはファイルの場所を、この文書か `docs/` 内に残している

## この作業ではやらないこと

- 高忠実度の見た目
- プロトタイプの遷移
- コンポーネントライブラリの作り込み
- アプリの実装
- Capacitor の導入
