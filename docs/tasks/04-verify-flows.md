# 04 操作確認

- [ ] 未着手

## 目的

ブラウザで主要フローを操作し、台本外でも動くことを確認する。

## 依存

[03 画面](03-screens.md) が終わっていること。

## 完了条件

- [ ] 明細を取り込み、事業用と私用を選んで承認できる
- [ ] 請求書の 1 行を 8% に変え、税額が税率ごとに 2 行へ分かれる
- [ ] 請求書を下書きで保存し、編集で源泉の基準と端数処理を上書きしてから、詳細の下部で発行できる
- [ ] 発行では PDF のダウンロードかアプリでの共有を選べる
- [ ] 源泉ありの請求を発行し、売掛金と売上の仕訳が税込合計で 1 本になる
- [ ] 入金の消し込みで事業主貸が入り、天引き額を直せる
- [ ] 見本の読み取りで日付・金額・取引先が入り、保存前に直せる
- [ ] 請求書を複製すると翌月の下書きになり、見積書への変換とは別の操作である
- [ ] 証憑を保存しても、それだけでは仕訳はできない
- [ ] 証憑の「追加」からかんたん入力で仕訳を作って紐付けられる
- [ ] 証憑の「紐付け」で、検索した登録済みの仕訳を選べる
- [ ] 「デモに戻す」で初期データに戻る
- [ ] 未実装の機能をオンにすると、一覧と理由が出る
- [ ] フッターのチャットを開くと専用の画面になる
- [ ] 履歴から過去のチャットを開け、新規で会話を開き直せる
- [ ] 入力欄の左に添付のプラスがある
- [ ] 未入金の件数を聞くと、ホームの件数と一致する
- [ ] 確認結果のメモを、この文書か `docs/` 内に残している

## この作業ではやらないこと

- 新しい機能の追加
- 方針の変更（変更が必要なら [../reference/](../reference/) を書き換える）
- 本番向けの性能計測や暗号化
