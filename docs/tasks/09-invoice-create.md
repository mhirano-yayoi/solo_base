# 09 請求書の作成と編集

- [x] 完了

## 目的

書類タブで請求書の一覧・新規作成・下書きの編集・品目の入力を使えるようにする。

## 依存

[06 設定](06-settings.md) が終わっていること。

## 完了条件

- [x] 書類で見積書、納品書、請求書を切り替えられる（この作業では請求書以外は空でもよい）
- [x] 請求書が下書き、未入金、入金済みの状態を持ち、下書きを編集できる
- [x] 明細行が税率 10% か 8% を持ち、8% の行に軽減税率の旨が出る
- [x] 新規作成は設定の既定値（源泉の基準、端数処理）で計算し、下書きの編集で請求書ごとに上書きできる
- [x] 請求書に発行者名、登録番号、振込先、宛名、請求番号、取引年月日、支払期限、税率ごとの税抜・消費税・税込が出る
- [x] 入力画面の保存がナビの右上にある

## 確認の仕方

- 新規作成で下書きを保存し、一覧と詳細に税の内訳が出ること
- 1 行を 8% に変え、税率ごとの内訳が 2 行に分かれること

## この作業ではやらないこと

- 発行と入金（[10](10-invoice-issue.md)）
- 見積書・納品書の本実装（[11](11-quote-delivery.md)）
